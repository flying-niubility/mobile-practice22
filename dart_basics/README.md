# dart_basics

实验二课堂案例：Dart 语言基础一示例合集（变量、类型、函数、控制流）。

## 入口

- `bin/dart_basics.dart`：依次运行 `types_demo`、`func_demo`、`flow_demo` 三组示例。
- `bin/safety_refactor.dart`：作业1，空安全改写前后对照。
- `bin/report_generator.dart`：作业2，实验报告生成器（命名参数三种调用）。
- `bin/grade.dart`：作业3，成绩分级器（0/100 边界与非法输入）。

## 常用命令

```bash
dart run
dart run bin/safety_refactor.dart
dart run bin/report_generator.dart
dart run bin/grade.dart
dart analyze
dart test
```
